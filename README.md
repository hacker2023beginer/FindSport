# FindSport

Веб-платформа поиска спортивных мероприятий на территории Республики Беларусь.

## Запуск

```bash
cp src/main/resources/application-example.yml src/main/resources/application.yml
docker compose up -d        # PostgreSQL 17 и Mailpit (тестовый почтовый сервер)
ADMIN_EMAIL=admin@findsport.by ADMIN_PASSWORD='Admin-pass-2026' mvn spring-boot:run
```

- Веб-интерфейс: http://localhost:8080 (вход, регистрация, личный кабинет)
- Кабинет поставщика: http://localhost:8080/provider.html (профили организаций и тренеров, мероприятия, фото и документы)
- Панель модератора: http://localhost:8080/moderation.html (очередь, сравнение версий, решения и их журнал)
- Публичная карточка мероприятия: http://localhost:8080/event.html?id=<id>
- Письма подтверждения и восстановления доступа: http://localhost:8025 (Mailpit)
- Документация API: http://localhost:8080/swagger-ui.html
- Тесты: `mvn test` (нужен запущенный Docker — Testcontainers)

`ADMIN_EMAIL`/`ADMIN_PASSWORD` нужны только при первом запуске: создается первичный администратор,
который назначает роли модератора и администратора (`/api/v1/admin/users`).

## Публикация карточек

1. Поставщик создает профиль организации или тренера и отправляет его на подтверждение.
2. Модератор подтверждает профиль — только после этого карточки организатора можно опубликовать.
3. Поставщик создает мероприятие (черновик), добавляет фото (jpg 0.1–5 МБ), документы (docx до 20 МБ)
   и видеоссылки Google Drive, отправляет карточку на модерацию.
4. Модератор видит отправленную версию, измененные поля и файлы, результаты автоматических проверок
   и публикует карточку или отклоняет ее с обязательной причиной.

Существенные изменения опубликованной карточки (название, дата, время, место, описание, медиафайлы) до
одобрения не видны посетителям — публично остается прежняя версия. Опубликованную карточку можно архивировать.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USERNAME`, `DB_PASSWORD` | как в `docker-compose.yml` | PostgreSQL |
| `MAIL_HOST`, `MAIL_PORT` | `localhost`, `1025` | SMTP (локально — Mailpit) |
| `MAIL_USERNAME`, `MAIL_PASSWORD`, `MAIL_SMTP_AUTH`, `MAIL_STARTTLS` | пусто / `false` | SMTP с авторизацией |
| `MAIL_FROM` | `no-reply@findsport.by` | Отправитель писем |
| `PUBLIC_BASE_URL` | `http://localhost:8080` | Адрес интерфейса для ссылок в письмах |
| `SESSION_COOKIE_SECURE` | `false` | `true` в среде с HTTPS |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | пусто | Первичный администратор |
| `UPLOADS_DIR` | `data/uploads` | Каталог загруженных фото и документов (вне каталогов приложения; включать в резервное копирование) |
